# Handwriting Reconstruction Engine · HRE 0.1

Локальная лаборатория для библиотеки собственного почерка: импорт фотографий,
выделение кандидатов, ручная разметка, проверенные фрагменты и сборка нового текста
с происхождением каждого элемента. Интерфейс на русском, поддерживаются отдельные
библиотеки образцов `ru` и `en`. Данные и обработка остаются на компьютере.

**Статус: работающее исследовательское ядро.** Это не обученная модель автора и
не завершённая система реалистичного восстановления почерка. Фотографии пользователя
в доступных папках не найдены. Включённые примеры — **синтетические шрифтовые
фикстуры**, которые не демонстрируют личный почерк и не оценивают его реализм.

## Быстрый запуск в Windows

В подготовленной локальной папке можно запустить `START.cmd` двойным кликом.
Открыть адрес, напечатанный в окне: [локальный редактор](http://127.0.0.1:8765).
Остановка сервера — `Ctrl+C`. Для отдельной демонстрационной библиотеки:

```powershell
.\START.ps1 -Demo
```

После клонирования требуется установленный Python с pip и доступ в интернет для
однократной загрузки uv, Python 3.13 и библиотек:

```powershell
python -m pip install uv
python -m uv sync --python 3.13 --locked
.\.venv\Scripts\python.exe -m hre --library library serve
```

На Linux/macOS после `uv sync --python 3.13 --locked` используйте `uv run python -m hre`.
`START.ps1` предназначен для Windows. Код и зависимости зафиксированы в `uv.lock`.
Python 3.15 не поддерживается этим набором CV-зависимостей.

## Работа со своими страницами

1. Импортировать PNG/JPEG/TIFF/BMP/WebP или ZIP. Оригиналы не изменяются:
   создаётся побайтовая архивная копия, SHA-256 и ориентированная sRGB-производная.
2. Нажать «Выделить кандидаты». Посмотреть маску чернил, строки/слова и скелет.
   Это геометрические гипотезы, без OCR и автоматического распознавания букв.
3. Выбрать карточку кандидата или нарисовать прямоугольник/полигон на странице.
   Полигон задаётся последовательными кликами; «Новая область» начинает новый.
4. Вписать точный текст без пробелов, язык и уровень: слово, фрагмент, символ, штрих.
   При необходимости задать baseline и точки входа/выхода через инструмент или JSON.
5. Указать проверяющего и выбрать «Проверен человеком». Сохранить. Любая смысловая
   или геометрическая правка снимает прежнюю верификацию, если явно не подтверждена
   заново. История и прежние маски сохраняются. Устаревшая версия формы отклоняется.
6. Во вкладке «Композиция» ввести текст и проверить покрытие. Собрать PNG и скачать
   JSON происхождения. Недостающие слова не заменяются; переполнение — ошибка.

Для исправления перспективы выбрать «Четыре угла страницы», отметить TL/TR/BR/BL
и нажать «Выровнять страницу». Создаётся отдельная версия с обратной матрицей
к оригиналу. Масштаб, панорама и контраст относятся только к просмотру.
«Качество и геометрия» показывает измерения без некалиброванного общего рейтинга.
Покрытие алфавитов считает отдельно подтверждённые character, не догадки о буквах
внутри слов. Демонстрацию собирать в явно выбранном экспериментальном режиме:
strict-real по умолчанию исключает synthetic.

Целые слова имеют приоритет. Для английского допустима сборка из подтверждённых
символов/фрагментов. Для русского куски внутри слова требуют совместимых вручную
поставленных anchors; алгоритм совмещает их координаты. Наличие anchors не доказывает
естественность соединения — она проверяется визуально. Штрихи не подставляются как текст.
Пунктуация требует соответствующих образцов. Текст чувствителен к регистру;
нормализация и замена похожих латинских/кириллических букв не выполняются.

## CLI

Команды ниже выполняются после активации окружения; в Windows можно заменить
`python` на `.\.venv\Scripts\python.exe`.

```text
python -m hre --library library import "D:\My notebooks" "D:\samples.zip"
python -m hre --library library analyze all
python -m hre --library library stats
python -m hre --library library doctor
python -m hre --library library export library-export.json
python -m hre --library library render --text input.txt --language ru --output page.png
python -m hre --library demo-library demo
python -m hre --library demo-library inventory --language ru
python -m hre --library demo-library report demo-library/renders/SYNTHETIC-russian.json
```

`input.txt` — UTF-8; допускаются обычные пробелы и переводы строк LF. CLI читает
Windows-переводы строк как LF. Табуляция и управляющие символы отклоняются.
Чтобы разместить крупные кропы, увеличьте `--line-height`, `--width`, `--height`.
Рендер не масштабирует образцы произвольно и не добавляет случайные деформации.

| `tests/test_engine.py` | инварианты, регрессии и API-интеграция |
| `docs/RESEARCH.md` | прочитанные источники и инженерные выводы |
| `docs/DESIGN.md` | архитектура, альтернативы и ограничения |
| `docs/VALIDATION.md` | проверенные сценарии и оставшиеся пробелы |

## Библиотека и происхождение

В `library/` находятся `originals/`, `pages/`, `analysis/`, `samples/`, `renders/`
и `library.sqlite3`. Идентификатор источника — полный SHA-256. Метаданные хранят
первоначальное имя/путь (для загрузки браузером исходный локальный путь недоступен),
размеры до/после EXIF, формат, ICC/хеш профиля и преобразования. Оригинал хранит
полный EXIF/ICC. Производная страница дополнительно защищена своим хешем.

Координаты bbox `[x0,y0,x1,y1)` и полигонов — пиксели **ориентированной производной**.
Baseline и entry/exit — локальные координаты кропа. Граница справа/снизу не включается.
Образцы имеют revision; имя маски содержит revision и хеш содержимого. Append-only
audit в SQLite сохраняет все правки. Это журнал приложения, не защищённая от владельца
компьютера криптографическая система регистрации событий.

PNG сопровождается JSON: точный текст, диапазоны символов, id/revision образцов,
координаты, хеш оригинала/производной/маски, язык, измеренный цвет, настройки и хеш
итогового изображения. Индексы текста — Unicode code points Python. Повторный
рендер в той же библиотеке с теми же параметрами даёт одинаковые пиксели/PNG.

**Резервное копирование:** остановить сервер и скопировать всю папку библиотеки.
JSON-экспорт — средство просмотра/обмена метаданными, не полная резервная копия
масок и оригиналов. Импорт старых ZIP-библиотек сейчас извлекает изображения;
неизвестные схемы аннотаций и названия файлов не считаются проверенными метками.

## Ограничения и следующий этап

- Сегментация — эвристическая: проекции и морфология. Связная пропись, наклон,
  бледные чернила, цветная сетка и исправления требуют ручной проверки.
- Маска — приближённое разделение чернил/бумаги. В точках пересечения сетки возможны
  потери штрихов. Прямоугольный фон не переносится; используется alpha + linear RGB.
- Не реализованы обученный HTR, разбиение связной прописи на достоверные буквы,
  восстановление порядка штрихов, обучение персональной коррелированной вариативности.
- Нет автоматического dewarp, анализа оптики конкретного фото и
  фотореалистичного повторного фотографирования. Гомография и mesh доступны как
  функции; ручная гомография подключена к редактору, mesh пока только API Python.
  Глобальный blur — ручной параметр API.
- Статистика по языкам описывает подтверждённые кропы в пикселях; разные масштабы
  фотографий несопоставимы без калибровки. Авторская модель по этим данным не обучена.
- Одностраничный экспорт; сложные раскладки, масштабирование и многостраничность
  требуют дальнейшей реализации. Базовая линия в UI горизонтальна.

Для следующего этапа нужны реальные страницы с согласованной ручной разметкой,
калибровкой масштаба, разделением train/validation/test **по исходным страницам**,
и оценкой сегментации/масок/соединений отдельно от визуального сходства.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
node --check hre/static/app.js
.\.venv\Scripts\python.exe -m hre --library demo-library doctor
```

Сервер привязан к `127.0.0.1`, без debug/reloader и внешних JS/CDN. Это локальный
инструмент для одного пользователя. Нет аккаунтов, сетевого совместного редактирования,
облачной загрузки или телеметрии. ZIP ограничен по размеру и не распаковывается на диск.
