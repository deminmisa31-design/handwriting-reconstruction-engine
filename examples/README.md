# Только синтетические фикстуры

Все изображения в этой папке созданы локальным шрифтом через `hre demo`.
Они не являются фотографиями пользователя и не воспроизводят его почерк.

`SYNTHETIC-source.png` — исходная фикстура. English/russian PNG сопровождаются
manifest и технической валидацией. Для полного воспроизведения библиотеки:

```text
python -m hre --library demo-library demo
python -m hre --library demo-library report demo-library/renders/SYNTHETIC-russian.json
```

JSON исходного примера содержит id масок из созданной demo-библиотеки. Сами
оригиналы/маски рабочей библиотеки не являются частью репозитория: их заново
создаёт команда demo. Итоговый PNG детерминирован в том же окружении/шрифте.
