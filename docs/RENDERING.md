# Композиция и рендеринг

Strict-real (по умолчанию) исключает источники synthetic. Experimental-synthesis
в этой версии только разрешает уже существующие явно синтетические фикстуры;
никакой генеративной модели в нём нет. Assisted mode не реализован и отклоняется.

Целый подтверждённый токен имеет приоритет; затем dynamic programming по fragments/
characters. Русские стыки требуют anchors с совместимой высотой относительно baseline
и положительным продвижением. Форма касательных и биомеханика не оптимизируются.
Тот же единственный вариант может повторяться; validation показывает reuse.
Неизвестный токен вызывает CoverageError с точными диапазонами.

Пробелы и LF сохраняются структурно. Слова переносятся целиком по границе страницы.
Baseline слов строки общая; anchors фрагментов совмещаются геометрически. Крупный
кроп не масштабируется молча: изменить шаг строк/размер страницы или разметку.

Извлечение: фон через closing и Gaussian blur, локальный RGB-контраст, подавление
слабых длинных линий, least-squares alpha при постоянном оценённом цвете чернил.
Alpha — приближение, не истинная прозрачность. Ink score не калиброванная вероятность.
Все сырые RGB-кропы сохранены отдельно, поэтому потерю тонкого края можно исследовать.

Композитинг в linear RGB: C = alpha*ink + (1-alpha)*paper, затем sRGB encoding.
В controlled-тесте цвета остаются между ink и paper, alpha=0 сохраняет фон.
Это доказывает отсутствие арифметического overshoot/undershoot на фикстуре,
но не отсутствие perceptual halos на реальной фотографии.

Бумага — детерминированная светлая поверхность, клетка/линейка/без сетки.
Физическая модель бумаги, заданная фототекстура, pigment scattering, нажим,
пространственная PSF, камера и повторное фотографирование не реализованы.
Ручной global blur применяется к бумаге и тексту вместе и записывается в manifest.
