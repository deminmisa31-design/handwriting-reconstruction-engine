# Архитектура

Вертикальный срез: импорт → EXIF/координаты → кандидат страницы → ручные углы
→ отдельная выровненная версия → выделение слова → точная подпись → подтверждение
→ evidence/alpha/metadata → библиотека → композиция → проверка происхождения.
На синтетике срез проверен; реальный вход пользователя пока отсутствует.

| Модуль | Программный интерфейс | Роль |
|---|---|---|
| store | `Store(root)`, import_file/import_bytes/import_zip | источники, SHA, pHash, транзакции |
| document | exif_matrix, transform_points, quality_report, detect_grid, page_candidates | координаты и измерения |
| imaging | extract_ink, ink_layers, segment, metrics, perspective, mesh_warp | чистая обработка массивов |
| store | rectify, analyze, add_sample, update_sample, audit, inventory | производные и разметка |
| compose | plan_text, render | точное покрытие, baseline/anchors, linear RGB |
| validation | validate_manifest, write_report | структурные проверки и отчёт |
| web | create_app(store) | локальный HTTP-адаптер |
| __main__ | main | CLI над теми же функциями |

Большое дерево модулей из спецификации заменено небольшими ответственными
модулями: это упрощает обозримость проверяемого среза без пустых заглушек.
CV не импортирует UI. Composer читает маски, не декодирует исходные фотографии;
проверка целостности источников выполняется через Store.

Оригинал и каждая выровненная версия имеют отдельные записи представления.
`root_source_id` связывает их с одним исходным SHA-256. Правка геометрии создаёт
новую view, не меняет старую разметку. Конкурирующие правки сериализуются SQLite
`BEGIN IMMEDIATE`, клиент сообщает expected_revision. Файлы масок содержательно
адресованы; отвергнутая правка не может перезаписать маску победившей версии.

При композиции используются согласованные snapshots образцов; изменение версии
между планированием и чтением вызывает отказ. Валидация связывает каждый placement
с конкретной проверенной audit-версией и её исходником, геометрией и хешами.

P2/P3 вынесены в ROADMAP.md. Большие нейросети, AI API и удалённые сервисы не нужны.
