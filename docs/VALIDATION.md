# Фактически выполненные проверки

Дата: 8 ноября 2026. Windows, Python 3.13.18, версии зависимостей в uv.lock.
Команда `.venv/Scripts/python.exe -m pytest -q`: **35 passed**.
`node --check hre/static/app.js`: синтаксических ошибок нет.

Проверены импорт/дедупликация SHA, неизменность файла, EXIF, ZIP traversal,
multi-frame отказ, пустые маски, bbox/polygon, ручная верификация, история,
перезапуск базы, закрытие Windows handles, конкурирующие и устаревшие правки,
revision race планирования, языковые фильтры, strict-real, Unicode и точный текст,
анкеры русских fragments, overflow, common baseline, детерминированный PNG,
гомография/remap identity, EXIF 1–8 roundtrip и соответствие Pillow, pHash/quality,
сетка на чистой фикстуре, сохранение geometry view, обратный polygon и evidence,
проверка связи исходника/геометрии с audit-версией, loopback/origin и API.

Контролируемый halo-тест проверяет корректность alpha=0/1 и отсутствие
поканального overshoot/undershoot при linear RGB blending. Это не визуальная
экспертиза ореолов на настоящих чернилах.

В браузере фактически проверены выбор образца, заполнение формы сохранённой
разметкой, сохранение с новой revision, создание русского PNG, ссылки PNG/JSON
и просмотр результата. Диагностирована и исправлена 404-ошибка PNG на Windows.
После дополнения в браузере проверены четыре клика углов, создание отдельной
выровненной версии (951×400), сохранение исходной 1000×440 и отчёт качества с
обратимым transform и явно невычисленными вероятностями (null).
