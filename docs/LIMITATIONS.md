# Реальные границы

Полностью проверены программные инварианты на синтетических фикстурах: SHA,
EXIF 1–8, обратные матрицы, отдельные выровненные views, ручные статусы/история,
строгое покрытие текста, bounds, версия/геометрия происхождения, локальный API.

Частично: эвристические page/grid/line/word detection, alpha, приблизительная
толщина штрихов, ручные русские anchors, статистика пиксельных размеров.
Пороговые значения алгоритмов не откалиброваны на реальных фото автора.

Не реализованы: HEIC-декодер; автоматический dewarp/сгиб/красные поля/рука;
достоверная вероятность смаза/окклюзии; обученный HTR; автоматическая сегментация
русских букв; stroke graph и temporal pen motion; касательные/контекстный scoring;
WriterStyleProfile с калиброванными распределениями/корреляциями; физический масштаб;
кисть маски, перетаскивание вершин, view rotation; фототекстура/модель камеры;
assisted mode; многостраничность; SSIM/morphology comparison dashboards.

В первоначальном срезе исходники не были найдены. Позже получены два приватных
кропа для локальной диагностики, но не полные оригиналы/эталонные маски.
Поэтому настоящая подтверждённая библиотека автора,
real-data tests, сравнение A/B/C/D и измерение сходства не выполнены.
Никаких процентов узнаваемости, качества HTR или персональной точности нет.
Созданная фикстура использует локальный шрифт; это явно synthetic.

Не подтвердились как достаточные подходы: независимый jitter и шрифтовая замена
не принимаются за модель автора; чтение связных компонент не принимается за
выделение букв. Эти ограничения следуют из постановки и анализа, не из проведённого
на авторских данных сравнительного эксперимента. Сравнение методов на них ещё впереди.

Лимиты: 50 MiB/файл, 40 MP импорт, ZIP 1000 entries/200 MiB суммарно,
20 MP выход, 10000 codepoints текста. Обработка изображения использует полноразмерные
массивы и может потреблять сотни MiB/несколько GiB; RAM-профилирование не выполнено.
На слабой машине лучше уменьшать производную до импорта, сохраняя оригинал отдельно.

Сервер однопоточный для одного пользователя. Файлы и SQLite локальны, без шифрования
приложения. Незавершённая операция может оставить сиротский производный файл,
но не должна менять оригинал/подтверждённую версию. Автоуборка таких файлов отсутствует.
