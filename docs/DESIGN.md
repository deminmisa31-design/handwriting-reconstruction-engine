# HRE: архитектура и границы версии 0.1

Задание: локальный воспроизводимый комплекс для исследования собственного почерка.
Выбор инженера в автономном режиме: Python 3.13, Pillow, NumPy, SciPy,
OpenCV, scikit-image, Flask; SQLite, локальный браузерный редактор без CDN.

## Рассмотренные подходы
1. Обучение diffusion: большие требования к данным/вычислениям, нет гарантии буквенной точности.
2. Конкатенация подтвержденных слов и фрагментов: точное происхождение и содержание,
   ограниченный словарь, требуется ручная проверка. Выбрана как проверяемое ядро.
3. Компьютерный шрифт: не восстанавливает личный почерк; применяется только для synthetic fixture.

## Поток данных
Оригинал → SHA-256 + побайтовая архивная копия → EXIF-нормализованная страница
→ оценка фона/чернил → маска/скелет/компоненты → кандидаты строк и слов
→ ручная транскрипция, полигон, baseline и верификация → библиотека
→ динамическое программирование покрытия текста → геометрия строк → RGBA
→ линейный композитинг → PNG + JSON происхождения.

SQLite хранит оригиналы, производные и образцы. Каждая правка образца сохраняется
в append-only audit. Переанализ страницы не удаляет ручную разметку.
Статусы: candidate, transcribed, verified, rejected. Автоматика не верифицирует.
Языки ru/en имеют независимые фильтры и статистику. Связность фрагментов задается
explicit entry/exit anchors: русские куски внутри слова допускаются только при
совместимых соединениях; целое слово имеет приоритет. Недоступный текст вызывает
ошибку покрытия, без молчаливой подмены.

## Границы
Это работающее исследовательское ядро, не обученная модель автора. HTR отсутствует:
кандидаты не получают догадок о буквах. Ручная perspective подключена к UI и создаёт
новую view с обратными матрицами. Mesh — низкоуровневая операция;
автоматическое восстановление изгиба листа не реализовано. Альфа —
приближенная оценка, не истинное физическое matting. Нет обученной модели оптики,
нажима, движений пера или коррелированной вариативности автора; случайные
деформации не применяются. Метрики формы — описательные, не доказательство личности.
Без фотографий нельзя подтвердить точность сегментации, реализм и узнаваемость.

## Инварианты
Исходник не изменяется. Все координаты — пиксели ориентированной производной,
прямоугольники half-open; исходная EXIF-ориентация сохранена. Каждый рендер хранит
исходный текст целиком, хеши оригиналов, версии образцов, координаты и параметры.
Рендер не обрезает текст при переполнении. Все демонстрации явно synthetic.
Сервер только 127.0.0.1, без облачного импорта/телеметрии. Архивы распаковываются
в память только для изображений, с ограничением размера и числа файлов.
