# Разметка

1. Импортировать свою фотографию/архив. Рабочая библиотека не загружается на GitHub.
2. Качество и геометрия показывают измерения без выдуманного общего рейтинга.
3. Для перспективы выбрать «Четыре угла страницы»: TL, TR, BR, BL. Нажать
   «Выровнять страницу». Размер результата оценивается по длинам сторон.
   Старый источник остаётся доступен. Изгиб страницы гомографией не исправляется.
4. Нажать анализ. Диагностика показывает alpha, оценку бумаги, score чернил,
   неопределённые пиксели, пересечения сетки, скелет и кандидаты строк/слов.
5. Масштаб/панорама/контраст меняют просмотр; исходные пиксели не изменяются.
   Снять «Рамки» для сравнения. Начать «Новую область», выделить bbox или полигон.
6. Подписать точное слово/фрагмент/символ/штрих, выбрать язык. Пустая область не
   проходит подтверждение. Не называть соединённый комплекс одиночной буквой.
7. Для фрагментов русского слова вручную поставить вход/выход и baseline.
   Совместимость проверяется ограниченно; касательные и естественность ещё не моделируются.
8. Указать проверяющего, выбрать подтверждение, сохранить. В библиотеке доступны
   поиск, состояния и история. Отклонение — обратимая замена удаления записи.
9. Метаданные и изображения можно скачать. Резервное копирование — вся библиотека
   после остановки сервера; JSON-экспорт сам по себе не сохраняет оригиналы/маски.

Нет автоматического исправления транскрипции и автоматического «verified».
Указанное имя проверяющего — локальная отметка, не аутентификация личности.
При редактировании в двух окнах устаревшее сохранение отклоняется; повторно выбрать
карточку после обновления страницы. Редактирование вершин перетаскиванием,
кисть маски и контекстные соседние буквы пока не реализованы.
