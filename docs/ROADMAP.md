# Дорожная карта по master specification

Текущая версия остаётся 0.1: наличие частей поздних этапов не означает их приёмку.

| Этап | Состояние | Следующая проверка |
|---|---|---|
| 0.1 импорт/геометрия/просмотр | работает на фикстурах; ручная гомография | настоящие фото, память, сложная перспектива |
| 0.2 ручная библиотека | bbox/polygon, baseline, anchors, audit | 10–20 размеченных страниц автора, UX маски |
| 0.3 сегментация/штрихи | эвристики и скелет; графа нет | эталонные маски, line/word IoU, тонкие точки |
| 0.4 профили | описательные размеры, inventory | калибровка клеткой/мм, распределения и корреляции |
| 0.5 компоновка | покрытие и одностраничный layout | английские варианты символов, held-out тексты |
| 0.6 русские соединения | ручные anchors, экспериментально | контекст/касательные, сравнение A/B/C/D |
| 0.7 чернила/бумага | приближённая alpha, linear RGB | реальные края/сетка/фототекстуры |
| 0.8 проверки/отчёты | provenance/bounds/text + JSON/HTML | визуальные side-by-side, морфология/интервалы |
| 0.9 устойчивость | SQLite, лимиты, регрессии | tiled обработка, recovery, профилирование |
| 1.0 приёмка | не достигнута | реальные сценарии 1–10 спецификации |

Следующий минимальный ввод: несколько собственных русских и английских страниц,
лучше без пересылки во внешние сервисы; указать смысл слов и размер клетки.
Разделять train/test по исходному SHA/странице, а не кропам. Сначала эталонные
маски/слова и геометрия, затем измерения и авторская статистика. IAM/RIMES не
считаются данными конкретного автора и не публикуются без проверенных условий.
